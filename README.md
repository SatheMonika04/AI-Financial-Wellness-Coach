# 💰 AI Financial Wellness Coach

> An AI-powered personal finance assistant that helps users understand, manage, and improve their financial habits using Machine Learning, NLP, and Generative AI.

> 🚧 **Project Status:** Under Active Development

---

## 📌 Overview

Managing personal finances is challenging for many students and young professionals. This project aims to simplify financial management by automatically analyzing expenses, predicting future spending, recommending budgets, detecting unusual transactions, and providing AI-powered financial insights.

The system combines Machine Learning, Natural Language Processing, and Large Language Models to deliver personalized financial guidance.

---

## 🎯 Project Objectives

- Automatically categorize expenses
- Predict future monthly spending
- Recommend personalized budgets
- Detect unusual or suspicious transactions
- Parse bank SMS and transaction descriptions
- Generate AI-powered financial insights
- Visualize spending behavior through interactive dashboards
